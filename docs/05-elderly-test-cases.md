# 乡策通 H5 适老验收用例（无语音）

> 对应 AC-08 / AC-08a～d + 高对比。演示账号：`13800000001` / `Demo@123`。

## A. 单元测试（自动）

| ID | 范围 | 命令 | 期望 |
|----|------|------|------|
| UT-H5-01 | `a11yPrefs` 字号循环/存储 | `cd web-h5 && npm test` | 标准→大字→特大→标准；写 `data-font` |
| UT-H5-02 | `a11yPrefs` 高对比 | 同上 | toggle 写 `data-contrast=high` |
| UT-H5-03 | `profileGate` 七步门禁 | 同上 | 齐备 ready；养殖缺存栏/购机缺类型未齐 |
| UT-H5-04 | `status` / `materialDisplay` | 同上 | 状态中文；材料展平与图片识别 |
| UT-BE-01 | `PolicyMatchNormalize` | `cd server && mvn test` | 小麦→RICE；畜禽→LIVESTOCK；家庭农场→FAMILY_FARM |

## B. 手工/浏览器点点点（主路径）

| ID | 步骤 | 期望 |
|----|------|------|
| UI-01 | 打开 H5 登录页，预填账号登录 | 进入首页，见「立即匹配补贴」与资料进度卡 |
| UI-02 | 点右下角字号浮钮循环 3 次 | Toast「标准/大字/特大」；标题与 Tab 变大且无叠字 |
| UI-03 | 点「高对比」 | Toast「已开启高对比」；背景变浅黄、字变黑；再点关闭 |
| UI-04 | 资料已齐时点「立即匹配补贴」 | 进入政策匹配列表，卡片有大「去申报」按钮 |
| UI-05 | 点「更多筛选」打开「显示暂不符合」再关 | 折叠不干扰；默认只见符合项 |
| UI-06 | 进某政策详情，点收藏星 | 热区可点；Toast 收藏成功；再点取消 |
| UI-07 | 点「去申报」进材料页 | 填写/预览按钮高度够大；可保存草稿 |
| UI-08 | 提交前确认框点取消 | 不提交；再点提交确认后成功（材料齐时） |
| UI-09 | 「我的」→申报进度；若有驳回点「重新申报」 | 二次确认；取消则不跳转 |
| UI-10 | 「我的」→退出登录 | 二次确认后回登录页 |

## C. 回归注意

- 不做语音播报。
- 匹配仍走 `GET /api/policy/match`，不刷全量政策作主路径。
- 镇管权限本用例不覆盖（属 Admin）。
