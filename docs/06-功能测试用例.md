# 乡策通 功能测试用例（v2.0）

> 测试对象：H5 老人端（5173）+ Admin 管理端（5174）+ Spring Boot 后端（8080）。
> 用例结构统一 AAA：**准备（Arrange）→ 执行（Act）→ 断言（Assert）**，任何工程师可复现。
> 自动单测清单见 `docs/05-elderly-test-cases.md` 与 `server/src/test/**`。
> 优先级：P0=阻断（发版前必过）、P1=重要、P2=一般。

## 测试环境

- 后端：`cd server && mvn package -DskipTests` 后 `run.bat`（端口 8080，注意 `--server.port=8080`）
- H5：`cd web-h5 && npm run dev`（5173）；Admin：`cd web-admin && npm run dev`（5174）
- 库：`root/123456@localhost:3306/xiangcetong`；演示账号 `15632489079`（张三峰）密码见项目记忆
